# Palin 🔄

**Palin** is a lightweight, flexible, and efficient Object Pooling module written in Luau for Roblox by LongDrives33. It optimizes game performance by mitigating the overhead of frequent instantiation and garbage collection of repetitive or heavy instances, such as projectiles, particle effects, or UI components.

## ✨ Features

- **Lightweight & Clean:** Written in Luau with clear, straightforward logic.
- **Dynamic Expansion:** Seamlessly scales the pool size automatically if your game demands more instances than initially allocated.
- **Custom Lifecycle Callbacks:** Decouple your object setup logic using fully custom implementation wrappers (`InitFn` and `EndFn`).
- **Safe Cleanup:** Destroys both active and free instances properly when disposing of the pool to avoid memory leaks.

## 📋 API Reference

### `Palin.Init(ObjectType, InitFn, EndFn, Expand?, PoolSize?) -> Palin`
Creates and pre-allocates a new object pool.
- `ObjectType`: `Instance` — The template instance to clone.
- `InitFn`: `(obj: Instance) -> ()` — Callback function invoked right after an object is taken from the pool.
- `EndFn`: `(obj: Instance) -> ()` — Callback function invoked right before an object is returned to the pool.
- `Expand`: `boolean?` *(Optional, defaults to `false`)* — If set to `true`, the pool will dynamically create new instances on the fly if it runs out of free objects.
- `PoolSize`: `number?` *(Optional, defaults to `5`)* — The initial number of instances to populate the pool with.

---

### `Palin:Release(Amount?) -> boolean`
Retrieves and activates a given number of objects from the pool.
- `Amount`: `number?` *(Optional, defaults to the size of the free list)* — The number of instances to pull.
- **Returns:** `true` if successful. If the pool is empty and `Expand` is `false`, it outputs a warning and returns `false`.

---

### `Palin:Hold(Object) -> boolean`
Returns an active object back into the pool.
- `Object`: `Instance` — The active instance to put back into the free list.
- **Returns:** `true` if successful. If the object is not found in the active jobs tracker, it outputs a warning and returns `false`.

---

### `Palin:Add(Amount) -> boolean`
Manually extends the pool by instantiating and adding a specified amount of objects to the free list.
- `Amount`: `number` — The number of new instances to append.
- **Returns:** `true`.

---

### `Palin:Destroy(EndFn?) -> boolean`
Cleans up and safely deletes the entire pool instance along with all generated game objects.
- `EndFn`: `boolean?` *(Optional)* — If `true`, it will forcefully run the `EndFn` callback for all objects currently active in the `Job` list before destroying them.
- **Returns:** `true`.
